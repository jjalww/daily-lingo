## Description (paste this whole block)

DailyLingo is a web app I designed and built to make learning Japanese and Korean feel like real life instead of a textbook. Each day it features a new native-level conversation — the way people actually talk — across three skill levels, from polite beginner basics to full-speed advanced slang.

Key features:
• Bilingual — switch between Japanese and Korean instantly
• Three difficulty levels (Beginner / Intermediate / Advanced)
• Speaking practice — say any line out loud and get a 0–100% pronunciation score using browser speech recognition
• Listen to every line spoken in a native voice
• Practice mode that hides translations so you can test yourself
• Toggleable romaji/romanization, key vocabulary, and native-speaker culture notes on every dialogue
• A daily-rotating featured conversation to build a learning habit

Built from scratch with vanilla HTML, CSS, and JavaScript — no frameworks — and deployed free via GitHub Pages. The conversation library is fully data-driven, so new dialogues can be added without touching the app logic.
